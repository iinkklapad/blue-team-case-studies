# Blue Team Case Studies

This repository contains cybersecurity investigations inspired by labs, homelabs, and real-world attack scenarios. Each case study follows a structured SOC workflow, including evidence collection, timeline construction, incident analysis, escalation notes, containment recommendations, and MITRE ATT&CK mapping.

The goal is to approach technical challenges as incident investigations rather than walkthroughs, documenting the analytical and operational processes used by blue team professionals.
